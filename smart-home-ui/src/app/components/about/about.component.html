About This Project

Hi! I’m Nataliy Repkina, and I completed this assignment myself. This project reflects my personal approach to tackling the task, showing how I understand Angular concepts and structure a real-world application. You can see the full source code on my GitHub: github.com/NataRep.

This project was developed as part of the RS School Angular course . Its main goal is to consolidate and demonstrate practical skills in building modern web applications using the Angular framework.

Key Angular Concepts

  • Standalone components and modular architecture
  • Reactive forms and validation
  • Routing and navigation
  • Services, dependency injection, and state management
  • Async data handling with RxJS and observables
  • Reusable UI components and dynamic templates

Additional Features

  • Creating and controlling modals through services
  • Handling user authentication and form interactions
  • Working with custom pipes and directives

The project structure and functionality are designed to reflect real-world development practices — from feature organization to interaction between components and services. This implementation demonstrates my personal solution and can serve as a foundation for building more complex Angular applications in the future.
